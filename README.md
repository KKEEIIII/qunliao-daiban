# 群聊待办（WeChat / QQ 群消息 → 待办清单 → 手机提醒）

把**微信群 / QQ 群**里的"待办"自动抽出来，变成一份清单，到点用**手机提醒**。
全程在你自己的电脑上跑：截图/OCR 采集 → 模型抽取 → 写进 `todos.json` → 计划任务到点推送。

> 面向"我不想天天折腾"的 Windows 用户：装完基本不用管，出问题会自己报（手机推送 + 右下角弹窗）。

---

## 它做什么

```
微信群/QQ 群
   │  ① 截图 + OCR（微信：屏幕 OCR；QQ：屏幕 或 Maa 后台）
   ▼
采集器（计划任务：每小时）→ spool 队列
   │  ② 本地预筛 + 模型抽取（只把"像待办"的句子发给模型，省钱）
   ▼
todos.json（待办清单）
   │  ③ 看板页勾"完成/忽略"（点确定当场写回）
   ▼
提醒器（计划任务：每 20 分钟）→ 到点推送
   │  ④ 微信通道（dsh-wechat-plugin）/ ntfy / 企业微信 webhook 兜底
   ▼
手机
```

## 安装（Windows 10/11 x64）

1. 下载 `群聊待办-部署包-vXXXX.zip` 并解压
2. 右键 **`安装.ps1`** → **用 PowerShell 运行**
   （无人值守：`powershell -ExecutionPolicy Bypass -File .\安装.ps1 -Yes`）
3. 双击 **`群聊待办\打开控制台.cmd`** → 填企业微信 webhook / 你的微信昵称 / 群白名单 → 点「**确定**」**当场生效**
4. 之后想改待办状态：双击 **`群聊待办\打开看板.cmd`** → 勾「完成 / 忽略」→ 点「**确定**」**当场写回**

安装器会顺便：创建 4 个计划任务、挂上待办插件、自动安装并启用微信/QQ 通道插件、可选的开机自启。

## 依赖

- **Windows PowerShell 5.1**（系统自带，不需要 Powershell 7）
- **Node.js**：只有"点确定即写回"的本机服务和写回操作需要（安装器优先用 DSH 自带的 node）
- **可选**：VC++ 2015-2022 运行库（QQ 后台采集用 Maa 时需要，缺了会自动退回屏幕模式并留日志）

## 一些设计取舍（踩过坑才这么做的）

- **页面不能直接改本机文件** → 所以设置页/看板由一个小服务（只监听 `127.0.0.1`，一次性 token）代劳，点确定即生效，用完自动停。
- **JSON 一律用 Node 写**：PowerShell 的 `ConvertTo-Json` 会写 BOM、还会把单元素数组压成字符串（历史上因此丢过数据）。
- **计划任务用 `wscript` + `run-hidden.vbs` 隐藏启动**：`powershell -WindowStyle Hidden` 仍会闪黑窗。
- **打包流程有两道"二进制体检"**：`.dll/.exe/.node` 必须 `MZ` 开头 —— 曾经因为一次"全目录补 BOM"的批处理把 Maa 运行库 23 个文件全写坏。
- 每条失败都留痕：`dsh-接入\logs\` + `运行状态.json`，自检靠它发现"跑过但没留痕"。

## 版本更新记录

### v20261106 · 2026-11-06（当前源码）

**微信采集可靠性**

- 新增窗口身份门禁：使用顶层根窗口归属，并核验微信进程名、窗口类名和标题；前台不属于微信时拒绝真实点击。
- 新增点击前整行复读：候选会话名字区分别以 3×、4× 放大 OCR，两档都匹配才点击；不确定时跳过并记录裁剪范围与识别结果。
- 识别会话列表是否滚离顶部；几何特征不够时改用 OCR 内容签名法，滚到内容不再变化为止。
- 忽略 `折叠置顶聊天`、`置顶聊天` 等界面分隔行，避免误点后折叠整个置顶区。
- fixture 离线测试改写独立日志，不再覆盖生产 `last-pass.txt` 和运行状态。

**QQ 采集可靠性**

- QQ 列表滚动点被遮挡时，临时置顶窗口、用 OCR 内容签名滚到顶部，再恢复原 z 序；不抢焦点。
- QQ 标题匹配支持群号、群人数后缀、标题截断和逻辑群别名，减少“正确点开但被标题校验误丢”的情况。
- 区分 QQ 进程未运行、主面板未打开、Maa 截图验证失败等状态。
- 修复通用输入守卫误把 QQ 当成微信的问题；微信专属身份校验只在微信调用路径启用。

**自检与发布**

- 手机自检消息只显示红灯/黄灯问题，正常项合并为一行数量。
- fixture 测试不污染生产运行证据。
- 新增列表归位、点击前确认和 QQ 标题匹配回归覆盖。
- 本轮回归测试通过；QQ 实机轮次达到 7/7 覆盖。

### v20261027-1246 · 2026-10-27

- **锚点 = 文本 + 时间**：`state\seen-anchors.txt` 由 2 列升成 3 列（key / 时间 / 行文本），旧格式照样能读。
  翻往期时**文本命中** 或 **时间越过锚点** 就停；当前屏最新时间 ≤ 锚点时间 → **一次滚轮都不发**（没有新消息就不折腾）。
  采集记录多一个 `sendTime`（消息发送时间，ISO），下游提示词不用改。
- **分辨率 / DPI 自适应**：微信会话行距不再写死 35px，按 OCR 行距自动校准（同一份 OCR 缩放到 0.5×~2× 都解析正确）；
  点击偏移改成"名字字高 × 0.55"；QQ 的兜底偏移按抓图高度折算。
- **修掉"点开的是别的群"的真因**：微信后台点击以前把"图像/窗口 1.23 倍"乘到客户区坐标上，越往下越偏；
  现在直接发客户区坐标，点开后轮询等渲染、点错群会重新定位再点一次。
- **白名单硬闸门**：点开后标题不在白名单 → 这条**直接丢弃**，不再写"越界记录"。
- **同一个群的容错判定**：OCR 把群名读残、或列表行名被截断时，也能认出"这和刚点开的是同一个群"。
- **三套离线回归测试**：`测试-解析.ps1`、`测试-时间锚点.ps1`（41 项）、`测试-分辨率适配.ps1`（13 项，含负向对照）。

- 修复开机自启指向临时目录或旧版 DSH 的问题，启动时自动核对并修正路径。
