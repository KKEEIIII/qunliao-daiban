# 群聊待办（WeChat / QQ 群消息 → 待办清单 → 手机提醒）

把**微信群 / QQ 群**里的"待办"自动抽出来，变成一份清单，到点用**手机提醒**。
全程在你自己的电脑上跑：截图/OCR 采集 → 模型抽取 → 写进 `todos.json` → 计划任务到点推送。

> 面向"我不想天天折腾"的 Windows 用户：装完基本不用管，出问题会自己报（手机推送 + 右下角弹窗）。

---

## 它做什么

```
微信群/QQ 群
   │  ① 截图 + OCR（微信：屏幕 OCR；QQ：屏幕 或 Maa 后台）
   ▼
采集器（计划任务：每小时）→ spool 队列
   │  ② 本地预筛 + 模型抽取（只把"像待办"的句子发给模型，省钱）
   ▼
todos.json（待办清单）
   │  ③ 看板页勾"完成/忽略"（点确定当场写回）
   ▼
提醒器（计划任务：每 20 分钟）→ 到点推送
   │  ④ 微信通道（dsh-wechat-plugin）/ ntfy / 企业微信 webhook 兜底
   ▼
手机
```

## 安装（Windows 10/11 x64）

1. 下载 `群聊待办-部署包-vXXXX.zip` 并解压
2. 右键 **`安装.ps1`** → **用 PowerShell 运行**
   （无人值守：`powershell -ExecutionPolicy Bypass -File .\安装.ps1 -Yes`）
3. 双击 **`群聊待办\打开控制台.cmd`** → 填企业微信 webhook / 你的微信昵称 / 群白名单 → 点「**确定**」**当场生效**
4. 之后想改待办状态：双击 **`群聊待办\打开看板.cmd`** → 勾「完成 / 忽略」→ 点「**确定**」**当场写回**

安装器会顺便：创建 4 个计划任务、挂上待办插件、自动安装并启用微信/QQ 通道插件、可选的开机自启。

## 依赖

- **Windows PowerShell 5.1**（系统自带，不需要 Powershell 7）
- **Node.js**：只有"点确定即写回"的本机服务和写回操作需要（安装器优先用 DSH 自带的 node）
- **可选**：VC++ 2015-2022 运行库（QQ 后台采集用 Maa 时需要，缺了会自动退回屏幕模式并留日志）

## 一些设计取舍（踩过坑才这么做的）

- **页面不能直接改本机文件** → 所以设置页/看板由一个小服务（只监听 `127.0.0.1`，一次性 token）代劳，点确定即生效，用完自动停。
- **JSON 一律用 Node 写**：PowerShell 的 `ConvertTo-Json` 会写 BOM、还会把单元素数组压成字符串（历史上因此丢过数据）。
- **计划任务用 `wscript` + `run-hidden.vbs` 隐藏启动**：`powershell -WindowStyle Hidden` 仍会闪黑窗。
- **打包流程有两道"二进制体检"**：`.dll/.exe/.node` 必须 `MZ` 开头 —— 曾经因为一次"全目录补 BOM"的批处理把 Maa 运行库 23 个文件全写坏。
- 每条失败都留痕：`dsh-接入\logs\` + `运行状态.json`，自检靠它发现"跑过但没留痕"。
